# AVG 初版程式

這是 `03_AVG` 的 C baseline 初版，依照規格：

```text
rd = floor((rs1 + rs2) / 2)
```

`rs1` 與 `rs2` 皆視為有號 32-bit 整數。程式使用 `int64_t` 儲存中間加總，
因此不會因為兩個 `int32_t` 相加而溢位；另外補正 C 語言對負數除法「向 0
截斷」的行為，以符合數學上的 `floor`。

## 編譯與執行

在 `1013` 資料夾中執行：

```powershell
gcc -std=c11 -Wall -Wextra -Wpedantic avg.c -o avg.exe
.\avg.exe
```

例如輸入：

```text
7 8
```

輸出：

```text
rd = 7
```
