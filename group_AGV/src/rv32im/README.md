# RV32IM baseline

本目錄實作 CP2 的 AVG 核心，只使用 RV32IM 指令，不使用任何自訂指令。
呼叫約定為 `a0 = rs1`、`a1 = rs2`，結果寫回 `a0`。

## 演算法

直接先做 `rs1 + rs2` 會在 32-bit 加法中溢位，因此使用等價公式：

```text
floor((a + b) / 2) = (a & b) + arithmetic_shift_right(a ^ b, 1)
```

## 統計

| 項目 | 數量 |
|---|---:|
| 靜態核心指令數 | 4 |
| 動態核心指令數／每次呼叫 | 4 |
| 分支指令數 | 0 |
| 記憶體存取指令數 | 0 |

統計範圍只包含 `avg_rv32im` 核心，不包含參數載入、函式呼叫、返回與
輸入輸出。
