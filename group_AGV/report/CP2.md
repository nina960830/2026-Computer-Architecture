# CP2：RV32IM AVG 實作

## 1. 本次目標

只使用 RV32IM 基本指令實作 AVG，並統計核心的靜態指令數、動態指令數與
分支數。

## 2. 設計內容

若先執行 `add rs1, rs2`，大值相加可能溢位。因此使用：

```text
(a & b) + ((a ^ b) >> 1)
```

右移是算術右移，對負數保留符號位元。對應的 `avg_rv32im` 位於
`src/rv32im/avg.S`：

```asm
and  t0, a0, a1
xor  t1, a0, a1
srai t1, t1, 1
add  a0, t0, t1
```

## 3. 結果與分析

| 項目 | 數量 |
|---|---:|
| 靜態指令數 | 4 |
| 動態指令數／每次呼叫 | 4 |
| 分支指令數 | 0 |
| 記憶體存取指令數 | 0 |

計數方法是原始碼的靜態指令計數，以及單次核心函式執行的動態指令計數；
不包含 `ret`、參數載入、函式呼叫與輸入輸出。本次未使用模擬器。

## 4. 遭遇的問題與解法

直接 `add` 再 `srai` 無法通過兩個 `2147483647` 的測試。改用 AND/XOR
分解平均值後，核心只需四條指令且不需要分支。

## 5. 白話說明

這個版本沒有請 CPU 先把兩個數完整相加，而是把兩個數相同的部分與不同
的部分分開處理，再組合成平均值。因此即使兩個輸入都很大，也不會在中途
超出 32-bit 範圍。
