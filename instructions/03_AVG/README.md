### AVG（向下取整平均）

- **語意（公式）**：`rd = floor((rs1 + rs2) / 2)`
  - `rs1`、`rs2` 皆視為 32-bit 有號整數
  - 中間值和必須以 **33-bit** 計算，不得溢位
  - 除法為**向下取整**（floor），不是 C 語言的「向 0 截斷」
- **運算元與定義域**：二元；`rs1, rs2 ∈ [−2³¹, 2³¹−1]`（即 `int32_t`）
- **結果範圍**：`[−2³¹, 2³¹−1]`
  - 最小：`(−2³¹) + (−2³¹) = −2³²`，`floor(−2³² / 2) = −2³¹`
  - 最大：`(2³¹−1) + (2³¹−1) = 2³²−2`，`floor((2³²−2)/2) = 2³¹−1`
  - 結果必然落在 `int32` 內，寫回 `rd` 不會溢位，不需要飽和
- **邊界條件與溢位處理**：
  - 中間值需 33-bit。若先做 32-bit `add` 再移位，第 33 位會被丟棄：
    `INT_MAX + INT_MAX = 2³²−2` 繞回 `−2`，`−2 >> 1 = −1`（正確為 `INT_MAX`）
  - 硬體等價式：`rd = (rs1 & rs2) + ((rs1 ^ rs2) >>> 1)`（`>>>` 為算術右移），
    此式不會產生進位，也不需要 33-bit
  - 負奇數：`(−3) + (−4) = −7`，`floor(−3.5) = −4`（算術右移直接得到）
- **測試向量（至少 3 組，含 1 組邊界值）**：

| # | rs1 | rs2 | rd | 說明 |
|---|---|---:|---:|---|
| 1 | 7 | 8 | 7 | 一般正值，和為奇數 → 向下取整 |
| 2 | −3 | −4 | −4 | 負奇數，驗證 floor 而非向 0 截斷 |
| 3 | 2147483647 | 2147483647 | 2147483647 | **邊界值**：中間值 2³²−2，需 33-bit |
| 4 | −2147483648 | −2147483648 | −2147483648 | 邊界值：中間值 −2³² |
| 5 | 2147483647 | −2147483648 | −1 | 正負邊界相消 |
| 6 | −1 | 0 | −1 | 最接近 0 的負奇數和 |

- **對應的 RV32IM baseline 片段與指令數**（詳見 [`1013/rv32im/`](../../1013/rv32im/)）：

```asm
# avg_bits：最短的正確版本，5 條（4 ALU + ret）
avg_bits:
        and   t0, a0, a1
        xor   t1, a0, a1
        srai  t1, t1, 1
        add   a0, t0, t1
        ret
```

| 實作 | 指令數 | 正確 |
|---|---:|---|
| `avg_wide`（64-bit 風格） | 10 | ✓ |
| `avg_shift`（拆移位） | 7 | ✓ |
| `avg_bits`（上表，最短） | 5 | ✓ |
| `avg_naive`（`add` + `srai`） | 3 | ✗ 溢位時錯誤 |
| **`avg` 自訂指令** | **2**（`avg` + `ret`） | ✓ |

## 指令編碼

依 HOMEWORK.md 第四節，自訂指令一律為 **R-type、opcode `0001011`（custom-0）**：

```
 31      25 24   20 19   15 14  12 11    7 6       0
+----------+-------+-------+------+-------+---------+
|  funct7  |  rs2  |  rs1  |funct3|  rd   | 0001011 |
+----------+-------+-------+------+-------+---------+
```

| 欄位 | 值 | 說明 |
|---|---|---|
| `opcode` | `0001011` (0x0B) | custom-0，規範固定 |
| `funct3` | `000` | **暫定**，依教師分配 |
| `funct7` | `0000000` | **暫定**，依教師分配 |
| `rs1` | — | 第一個運算元（有號 32-bit） |
| `rs2` | — | 第二個運算元（有號 32-bit） |
| `rd` | — | `floor((rs1+rs2)/2)` |

> `funct3` / `funct7` 由教師分配。若分配值不同，只需修改
> `1013/rv32im/rv32im_sim.py` 的 `AVG_FUNCT3` / `AVG_FUNCT7` 兩個常數。

範例：`avg a0, a1, a2` = `0x00C5850B`
（funct7=`0000000`, rs2=`01100`, rs1=`01011`, funct3=`000`, rd=`01010`, opcode=`0001011`）
